# LOVE.EXE ♡

Site criado como presente de aniversário para a Lucilly, reunindo fotos, músicas, mensagens e surpresas inspiradas na história de vocês.

## O projeto

- Galeria de fotos com memórias especiais;
- Playlist personalizada;
- Carta de aniversário interativa;
- Mensagens escondidas e easter eggs;
- Identidade visual em tons de rosa, lilás e fundo escuro.

## Tecnologias

- HTML
- CSS
- JavaScript
- Web Audio API

## Publicação

O site pode ser hospedado gratuitamente pelo Netlify ou GitHub Pages.

Feito com carinho para a Lucilly. ♡
